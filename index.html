طريقة حفظ ونشر الكود على GitHub Pages

يمكنك تحويل هذه الصفحة إلى موقع إلكتروني متاح للجميع عبر الإنترنت بطريقة مجانية تماماً باستخدام ميزة (GitHub Pages). إليك الخطوات البسيطة:

  1. 1
    إنشاء حساب وملف جديد قم بتسجيل الدخول إلى حسابك على GitHub، ثم انشئ مستودعاً (Repository) جديداً وليكن باسم ibra-quiz واجعله عاماً (Public).
  2. 2
    حفظ ملف الكود قم بنسخ هذا الكود بالكامل واحفظه في ملف نصي بصيغة HTML وسمِّه index.html.
  3. 3
    رفع الملف إلى المستودع من داخل المستودع على GitHub، انقر على خيار Add file ثم Upload files وارفع ملف index.html واضغط على Commit changes.
  4. 4
    تفعيل النشر التلقائي (GitHub Pages) انتقل إلى إعدادات المستودع (Settings)، ثم من القائمة الجانبية اختر Pages. تحت قسم Build and deployment اختر الفرع main (أو master) مع مجلد / (root) واضغط Save.
